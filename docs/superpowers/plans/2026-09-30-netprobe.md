# CQU NetProbe Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. User requested direct development in this session.

**Goal:** 交付从内网 Prometheus 读取数据的公开网络监控面板。
**Architecture:** Node 标准库后端，Vue 静态前端；服务器端配置数据映射。固定查询 API 及缓存，图表懒加载。
**Tech Stack:** Node >=22, Vue 3, Vite, TypeScript, Vue Router, uPlot.
**Spec:** ../specs/2026-09-30-netprobe-design.md

## Global Constraints
- 无采集、数据库、认证、Go 或 Nginx；后端零运行时依赖。
- 初始指标未配置，暂无数据保持空白，不生成演示数据。
- 服务端 PromQL 不接受客户端覆盖，所有公共输出隐藏 URL 和凭据。

## Review Focus
- 部分探针掉线不能被平均值掩盖；NaN/过期不能成为在线。
- 查询失败、真实空结果与未配置三类状态必须可区分。
- 历史路径限制楼栋，确保转义标签且限制序列/点数。
- 刷新/路由变化取消旧请求，移动布局不横向溢出。
- 缓存与并发有界，关闭进程终止请求。
